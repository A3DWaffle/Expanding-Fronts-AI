# Counter responses — November 9, 2026

TL3 Airbases now give an affordable, below-target Bomber counter package priority over Fighters when a mech alert is active. P3/P4 alerts use the existing P2 Bomber cap; the old Fighter prerequisite and passive-age block no longer prevent a response. Once the Bomber target is met, or Bombers cannot train, Fighters resume. Existing population/difficulty/map package targets are retained.

Visible mech observations remain immediate where the engine supports them. A delayed fallback samples the seven existing mech families on the Jedi intelligence clock: snapshots 105 seconds apart, publication 45 seconds after sampling. The fallback cannot react to hidden changes during that delay. It merges with the existing 300-second mech memory and never downgrades a stronger remembered sighting. Per-family bands remain coarse; this does not sum every mixed composition.

A published nonzero Jedi warning now permits replenishment to the existing Hunter cap until a newer NONE estimate replaces it. Production no longer consumes the warning after one order or closes it after 15 seconds. All Hunter tiers can use food/carbon military escrow. Sampling cadence, publication delay, supported Jedi families, and unit caps are unchanged.

Pummels are requested at TL3+ only while enemy-buildings-in-town is true: up to two including queued units, or one at population 25. The response can request one Heavy Weapons Factory outside the normal lineup, subject to building/power/raid gates. Heavy Pummel research requires an existing Pummel and enemy buildings in town. No global attack command, radius override, or targeting override is issued. During a Town Size Attack the town radius may be expanded, so this condition can include offensive siege targets. Native combat still chooses movement and exact targets; dedicated Pummel micro is not available in the current scripting interface.

Validation evaluates actual rules with supplied facts, including negative visible mech counts, stale snapshots, Hunter replacements, and competition for one Airbase slot. It cannot validate native vision, pathfinding, accepted queues, or Pummel targeting in a live match. Fresh TL3 Strike Mech and Jedi tests plus a building-in-town Pummel test remain necessary.
